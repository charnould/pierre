# Enrichir votre instance de PIERRE avec vos connaissances propriétaires

Il y a deux façons d'enrichir une instance de PIERRE avec vos données propriétaires : via `Administration > Encyclopédie` dans l'application desktop ou programmatiquement via l'API. PIERRE accepte aujourd'hui les fichiers CSV UTF-8 séparés par `;`, DOCX, Excel et Markdown.

L'interface permet de choisir les profils autorisés et, pour les classeurs, les onglets et lignes d'en-têtes à importer. Une source sans profil reste visible mais n'est utilisée par aucun agent.

Le détail d’usage de l’écran est dans le manuel : [Administration · Encyclopédie](../07-user-manual/20-admin-encyclopedie.md). Le détail de préparation des fichiers est dans [préparer vos documents pour PIERRE](./01-preparer-vos-documents.md). C'est le document à transmettre aux équipes-métier avant une première campagne d'alimentation documentaire.
