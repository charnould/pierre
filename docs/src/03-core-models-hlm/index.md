# CORE MODELS HLM

**Core Models HLM** est une famille de modèles de langage open-weight, auto-hébergeables et hyper-spécialisés, conçus pour les besoins concrets des bailleurs sociaux. Frugaux et souverains, ils fonctionnent sur n'importe quel serveur et sans GPU. L'approche retenue est un modèle adapté à chaque tâche plutôt qu'un modèle-frontière propriétaire, énergivore, surdimensionné, lent et coûteux.

- [CARL](./CARL.md) qualifie en 50 millisecondes le message d’un locataire ou d'un candidat HLM parmi 270 motifs possibles. Il ne répond pas : il qualifie, pour simplifier les traitements ultérieurs, humains, automatisés et agentiques.
